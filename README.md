# Regression & Principal Component Analysis

**Course:** MATH 311 – University of Alabama<br>
**Language:** Python<br>
**Libraries:** NumPy, Matplotlib, scikit-learn<br>

## Project Overview

This project explores regression analysis and principal component analysis (PCA) using Python. The goal was to evaluate regression models and examine how reducing the number of features affects model performance.

## Methods

- Built and evaluated regression models using Python.
- Applied principal component analysis (PCA) to reduce dimensionality.
- Compared model performance using R² scores.
- Examined explained variance to evaluate the effects of PCA.

## Skills Demonstrated

- Python programming
- Regression analysis
- Principal component analysis (PCA)
- Data analysis and visualization
- Model evaluation
